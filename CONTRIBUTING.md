# Contributing

1. Open or pick an issue.
2. Branch from `main` as `<type>/<issue>-<short-name>`, for example `fix/42-empty-route`.
3. Write commit and PR titles as commands: imperative, capital first letter, ending with a period.
4. Open a pull request that says `Closes #<issue>`, and wait for CI to pass.
5. Squash-merge. The branch is deleted after the merge.

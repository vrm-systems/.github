# .github

This repo holds the public profile and the shared community files of the vrm-systems organization.
GitHub applies the issue forms, pull request template, and policies to every repo in the org that has none of its own.

## Layout

```text
profile/README.md       public organization page
.github/                issue forms and pull request template
CONTRIBUTING.md         contribution workflow
SECURITY.md             how to report a vulnerability
```
